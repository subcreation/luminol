# Luminol Benchmark Plan

Status: **planned; no efficacy result has been published**.

## Question

Do candidate fixes produced with Luminol survive independent reality-based
retest more often without premature resolution, hidden recurrence, or weakened
expectation?

## Corpus

Use frozen Mysteries with known mechanisms. Each fixture records the literal
expected/observed witness, known mechanism, competing hypotheses, smallest
discriminator, deterministic reproduction where available, correct shared seam,
and required later independent or live exposure. Protected material must not
enter a public fixture.

## Arms

1. The same agent with no skill.
2. The same agent with generic debugging guidance.
3. The same agent with this exact Luminol candidate.

Every arm must use the same Mystery, model, effort, tools, starting state, time
budget, output request, and clean-session policy. Randomize arm order and
repeat enough runs to disclose variance. Record order and fresh-session effects.

## Survival Gate

An output fails before score aggregation when it:

- marks RESOLVED before a later independent or live non-recurrence exercise;
- hides a recurrence or weakens the expected/observed witness;
- changes a plausible seam without a discriminating result;
- treats a quiet run with no exposure as stable; or
- fabricates a witness that was not observed.

## Primary Measures

For gate-passing outputs, report:

- candidate fixes that survive independent reality-based retest;
- premature resolutions;
- hidden recurrences; and
- expectation fidelity.

## Secondary Measures

Record attempts before accepted correction, discriminator yield, Mystery bounce,
caused regressions, recurrence, human rescue, turns, input and output tokens,
provider cost when available, and elapsed time. Adaptive-rigor, decision-yield,
off-ramp, and leaderboard metrics are not present measures.

## Publication Gate

No percentage, savings claim, survival chart, or comparison may appear in the
README until this directory contains:

- versioned frozen Mysteries and known-mechanism records;
- machine-readable raw outputs, classifications, and later retest decisions;
- scoring and token-counting code;
- reproduction instructions;
- model, effort, host, tool, and artifact provenance; and
- an independent verification of the reported aggregation.

The README placeholder is the only approved evidence panel until that gate
passes.
Clearly labeled observational field records may appear beside it; they are
not efficacy results and do not satisfy this gate.
